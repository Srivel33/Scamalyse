# Scamalyse

**Pitch:** AI-powered internship and job offer scam detector — identify warning signals before you apply.

## Technology Stack
- **Frontend:** React + Vite
- **Backend:** Python + FastAPI
- **Database:** SQLite (planned)
- **AI:** Gemini API (gemini-3.1-flash-lite)

## Development Status
- **Phase 1 (Foundation):** Project structure initialized.
- **Phase 2 (Backend):** FastAPI server, risk engine, Gemini extraction, privacy redaction, 43 unit tests.
- **Phase 3 (Frontend):** Full React UI with risk assessment, evidence cards, clarification flow.
- **Phase 4 (Integration):** Frontend connected to backend via Vite proxy and API service layer.
